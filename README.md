# BlueDrop Pets - Frontend

Sistema de gerenciamento veterinário desenvolvido com Angular 17.

## 🚀 Tecnologias

- Angular 17
- TypeScript
- Standalone Components
- Angular Router

## 📦 Instalação

```bash
npm install
```

## 🏃 Executar o projeto

```bash
npm start
```

O projeto estará disponível em `http://localhost:4200`

## 🏗️ Build

```bash
npm run build
```

## 📁 Estrutura do Projeto

```
src/
├── app/
```

## 🎨 Funcionalidades

- Dashboard com estatísticas
- Menu lateral de navegação
- Busca de tutores, pets e agendamentos
- Visualização de atendimentos recentes
- Interface responsiva e moderna
- Roteamento entre páginas
